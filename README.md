# E-Commerce Sales Analytics

## Project Overview
An end-to-end data analytics project analyzing e-commerce sales data using Excel, MySQL, and Power BI to identify sales trends, profitability, product performance, and regional insights.

## Tools & Technologies
- **Excel:** Data analysis, pivot tables, and dashboard
- **MySQL:** SQL queries, aggregations, joins, subqueries, CTEs, and window functions
- **Power BI:** Interactive dashboard and data visualization

## Dataset
The dataset contains order information, customers, products, sales, discounts, quantities, and profits.

## Project Structure
- `data/` – Dataset
- `excel/` – Excel dashboard
- `sql/` – SQL analysis queries
- `powerbi/` – Power BI dashboard

## Analysis Performed
- Key performance indicators (KPIs): sales and profit
- Regional sales performance
- Category and sub-category analysis
- Top products and customers
- Sales trends over time
- Discount and profitability analysis
- Customer segment analysis

## Key Learnings
- Data analysis using Excel and SQL
- Writing SQL joins, CTEs, subqueries, and window functions
- Creating interactive Power BI dashboards
- Presenting business insights through visualizations
